# Contributing

Documentation corrections and concise, non-sensitive conceptual examples are welcome. Explain which statement needs correction and link to the relevant public vendor reference where possible.

Do not post customer environments, credentials, plans, state files, cloud logs or private incident details. This repository is a guide, not an incident-response or account-access service.

Do not use other projects' issues to advertise this guide or the related software. Technical contributions should solve the issue being discussed and follow that project's contribution rules. Promotional material belongs only in relevant sections of this project's own documentation.

By submitting a contribution, confirm that you are authorized to share it publicly. Commercial software, installation packages and customer support materials are maintained separately.
